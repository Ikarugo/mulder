## Analysis of Misses and Errors

### Same extractor output, different path through it

The masquerade line counts (17 on rm2, 0 on rm1, 3 on the PC) and `optical.listing` (58 lines) are what run 1 consumed; the differences between the two reports are the model's. This run made twice the tool calls (491 against 242) and spent 40% more tokens (14.0M against 10.0M) for the same 0 / 12–13 / 7–8 shape: the extra calls went to `search` (79 against 72), the `find_*` composite searches (51 calls across lateral movement, defense evasion, persistence and file staging, none of which yielded a graded fact) and `get_investigation_summary` (17), not to the registry and event-log sources that carry the missing items.

### What came back (items 3, 12)

RM1 is named by its label and its folder ("An 'Authorized USB' volume label was found containing 'Secret Project Data' directory structure"), the first time in a DeepSeek run, and the USBSTOR service key's LastWrite is reported as "USB Mass Storage Driver (USBSTOR.SYS) registry modification on March 24, 2015 at 13:37:59". Both move from MISSED to PARTIAL. Neither goes further: `USBSTOR` was queried three times (once against rm2's hive, which has none) and the output not read into a finding, so no serial, vendor or model, and no EVTX event.

### What was lost (item 19)

The `.ost` reference that made run 1's item 19 a PARTIAL is absent; the suspect's address is now a `bulk.email` hit on the disc, filed as a government contact. `bulk.rfc822` (7,327 lines) is again indexed and unread, and `parse_pst` is again never called.

### Registry values queried and dropped (items 2, 12, 20)

`InstallDate` (twice), `TimeZoneInformation` (four times) and `USBSTOR` (three times) were all queried through `query_registry_value`; each produced a one-line `registry.query.system` source that no finding cites. Run 1 read `InstallDate` and `ProductName` into finding 16 ("Windows 7 Ultimate", 1427034866); this run reports "Windows 7 (version 6.1)" from Windows Update filenames instead. The report has none of the OS edition, the architecture, the computer name, the timezone or a device serial, and every one of them was one `get_raw_output` away.
